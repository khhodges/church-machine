Tuple containment evidence

The tuple tests use the existing 58-word Thread heap record, not the designer’s illustrative 18-word layout. Alice and Mallory run in separate Threads. Alice uses her CR5 heap; Mallory’s test driver has no grant to Alice’s heap. The allocator reserves fixture storage; real DWRITE/DREAD instructions exercise Alice’s access. Mallory attempts DREAD through an empty capability register and faults without retiring the read. No tuple ACL or new security mechanism is introduced. The tuple regression uses explicitly pinned baseline Alice/Mallory fixtures, not the latest editor revisions. This is a bounded simulator regression, not a proof for every attack, FPGA validation, or a Dijkstra messaging test.
