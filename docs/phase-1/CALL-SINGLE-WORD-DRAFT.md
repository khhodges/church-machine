# CALL — approved Phase 1 formats

The filename is retained for existing links; these formats are approved.

Use the **[Master ISA CALL encodings](01-isa/instruction-set.md#approved-call-encodings)**
for all three forms: direct immediate, direct runtime-method, and indexed C-list.
Each is one 32-bit instruction. No multiword form is approved.

[Historical approval and worked example](05-review-history/call-encoding-review.md)
are preserved separately, not maintained as a competing specification.
