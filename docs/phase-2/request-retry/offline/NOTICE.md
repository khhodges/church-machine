## Dated modification notice — 2026-11-10

The offline package extracts the Session class verbatim from the retained
responder with offline imports only. It removes the opening machine-local
serial-port label from the event log and normalizes JSON formatting. The
manifest records the original hashes and those transformations.
The capture, result, protocol and physical report remain byte-for-byte intact.

offline tooling, not the historical responder. The compliance preparation
