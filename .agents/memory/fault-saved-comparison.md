---
name: Fault saved-artifact comparisons
description: Historical bytes and current saved artifacts are independent evidence.
---

Fault inspection must compare recorded raw words and captured execution identity with the inspected saved revision. Never promote a slot's current occupant, same-name revision, or one identical word into historical artifact identity. Capability labels supplement encoded CR numbers; dynamic DR indices remain numeric and distinct from fixed local C-list rows.

**Why:** A fault can agree with the committed memory image while disagreeing with a newer saved LUMP. Matching an image to an older artifact explains an image-versus-file difference but does not independently bind an earlier fault to that image.

**How to apply:** Preserve unknown identity, retain captured evidence across resets, and require captured identity plus complete code agreement before highlighting or mapping source. Saved names come only from inspected binary definitions; authored comments are not verified Namespace mappings.

Check the committed image's resident bytes and full artifact/provenance hashes before relying on a synthetic execution of the latest saved LUMP. Do not regenerate an image while investigating its historical contents.
