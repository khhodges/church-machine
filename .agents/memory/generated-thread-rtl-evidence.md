---
name: Generated Thread RTL evidence
description: Keep exact generated bodies distinct from fixture-provisioned native Namespace dependencies.
---

When replaying authored Thread initialization, distinguish unchanged generated
Thread-body evidence from complete public-image or full-core acceptance.

**Why:** The server and legacy scheduler have different Namespace address
formats, and a native projection can retain factory dependencies instead of the
selected ones. Supplying missing actors in a private fixture proves restoration,
not public upload completeness. Historical actor files also need current exact
admission checks; a familiar filename is not sufficient evidence.

**How to apply:** Freeze and compare complete Thread bodies before replay;
disclose any fixture-only resident provisioning and preserve selected authority.
Never translate instructions or repair state during the RTL bus replay. Keep
model first-entry results separate from actor execution and physical acceptance.
