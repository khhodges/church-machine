CLOOMC

compile → hash → seal → bind

Every name and what it currently means. A name is a binding, not a file — changing it mints a new Lump and points the name at it. Nothing is edited in place, so every past meaning stays fetchable.

Write a Method, compile it, give it a name. The hash is the version — identical source produces an identical hash, so there is nothing to number.

Lumps that declare a capability the namespace has not bound yet. The compiler does not report these and is right not to — a declared capability with a null Golden Token is a valid, deployable state, and binding it is load-time work. This is that work.
