Remaining blockers—not corrected by changing selectors

  1. Native services: select qualified Amoeba and SecurityRegulator implementations; implement the application service entry and its pre-dispatch loading sequence.
  2. Authority: provision only Genesis-authorized grants. Neither the presence of M_BIT_DEV nor a Resident policy establishes SecurityRegulator-only custody. No automatic grants were issued.
  3. Cross-Namespace references: exact Namespace identities, generations, target extents, request storage and service bindings remain unresolved. The current editor has no dedicated external-Namespace-reference row kind; no fake code or MMIO row was substituted.
  4. Thread initialization: prepare valid SYSTEM and USER continuations and fresh Mallory attempts. Clearing incompatible old templates does not initialize replacements.
  5. Dependency binding: all retained exact artifacts require explicit new-destination bindings. In particular, device and Thread import names must be resolved deliberately; Mint and Cleaner need their private data/services. No binding operation was performed.
  6. Physical placement: the editor fixes each draft at 16,384 words (64 KiB) and 64 slots. These remain nominal editor capacities, not approval of equal physical partitions. Final disjoint placement, common LUMP allocation and separate 16 KiB staging still require the combined-image builder.
